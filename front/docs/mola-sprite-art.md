# Mola — novos frames de animação

Gerados com a ferramenta integrada ImageGen. O atlas original definiu a identidade; a prancha enviada pelo usuário definiu a direção visual. As imagens finais foram copiadas para o projeto e codificadas em WebP sem perdas. Cada sequência tem oito desenhos distintos, em grade 4×2 de 1536×1024 pixels.

## Arquivos

- `mola-slinky-8-frames-com-pes.png`: compressão, alcance, arco, levantamento traseiro, passagem por cima, fechamento, aterrissagem e recuperação.
- `mola-caminhada-8-frames.png`: caminhada com pés alternados, para transporte de tasks.
- Projeto: `public/mascot/mola-rainbow/slinky-poses-feet-v2.webp` e `public/mascot/mola-rainbow/walk-poses-v2.webp`.
